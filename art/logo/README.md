# Title logo

`eggshell-logo.png` is the logo at the top of the project README. It is
183x87 art pixels, stored at 6x (1098x522) so that the README can show it at
3x (549x261) without blending pixels on 1x and 2x screens.

Nano Banana Pro (`gemini-3-pro-image`) drew it from text prompts and edits of
its own earlier drafts. No other game's artwork went into these calls. The egg
spots were then recoloured from teal to blue by a script that changes only hue
and saturation. The image was cut onto the generator's 14.35 px pixel grid
(the mode colour of each cell, never an average), and the white background
and letter holes were made transparent.

Prompts, drafts and the scripts are kept outside Git in
`~/.local/share/eggshell/art-direction/logo/`.
