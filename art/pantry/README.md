# Pantry art sources

These ten images are Nano Banana Pro (`gemini-3-pro-image`) outputs, generated
on 2026-10-23 through CLIProxyAPI. They are the exact returned bytes. The two
style references sent with the prompts were earlier Nano Banana Pantry concept images
(a bread-and-wall screen and a character sheet). No original-game imagery was
sent. The sources do not ship in the game; `tests/test_pantry_bread.py` pins
their SHA-256 hashes.

`tools/build_pantry_pack.gd` builds `packs/pantry/` from them offline. It
crops, colour-keys the magenta sheet background, resizes, makes materials
tile with a half-period cross-fade, adds crust and depth shading along
internal collision edges, tints set-back layers, and masks every terrain slot
with its fixed collision shape. The build is byte-reproducible with the pinned
Godot version. Model regeneration is not deterministic: a changed source needs
review and new hash pins.

```sh
godot --headless --path . --script tools/build_pantry_pack.gd
godot --headless --path . --editor --import
```
